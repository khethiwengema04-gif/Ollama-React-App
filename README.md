# AURA AI

# The Project Description

This project is about creating a simple AI chatbot application using React and Ollama. The application allows users to enter prompts and receive AI-generated responses through a locally running Ollama model. It includes a chat interface, loading spinner, response duration, tokens per second, and conversation history saved using LocalStorage. A system message is also used to define the AI assistant's purpose and behaviour.

# Installation and Set-up

```bash
# Clone repository
git clone https://github.com/khethiwengema04-gif/Ollama-React-App.git

cd Ollama-React-Project

# Install dependencies
npm install

# Install Ollama from:
https://ollama.com/download/windows

# Download AI model
ollama pull smollm2:360m
```

# Run App

```bash
# Start React application
npm run dev

```
